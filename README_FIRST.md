## Linking policy

The site systematically provides clickable access routes for publications and communications. The priority order is:

1. DOI / publisher / official open-access page;
2. stable repository or full-text page (HAL, RIHM, ResearchGate where appropriate);
3. clearly labelled official project/event/institutional context when the exact item is not publicly archived.

MOVICI working papers link directly to the corresponding pages of the MOVICI website.

## Language policy

Navigation, descriptions and explanatory text are in English. Published titles, official conference titles, official course names and student thesis titles are retained in their original language to avoid altering the academic record.
