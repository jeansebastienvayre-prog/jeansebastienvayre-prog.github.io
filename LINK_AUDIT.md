# Link audit — V5

V5 uses **no generic Search buttons and no Google/Google Scholar search URLs** anywhere in the website.

## Access-link policy

Buttons are shown only when an identified public resource exists. Labels state what the user will open: **Full text, Article, DOI, Publisher, HAL, Proceedings, Program, Event page, Journal, Project page, Institutional record, Research context, Related output**, etc.

Priority order:

1. exact full text or exact article page;
2. DOI / publisher / repository;
3. official proceedings or programme;
4. official project, event or institutional page;
5. a clearly labelled related output when the exact item is not publicly archived.

If no useful public resource is identified, the site should display the record without inventing a search button.

## Reviewing section

Reviewing records use exact article pages when publicly identifiable. For unpublished or non-public reviewed manuscripts, the button may point only to the relevant journal or official programme and is labelled accordingly.

## Layout

Record text and access buttons remain in separate responsive grid columns. Long labels wrap within the button and move below the record on narrow screens, preventing overlap.
